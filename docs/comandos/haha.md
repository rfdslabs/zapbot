# `/haha` (`/kkk`, `/rs`)

Manda uma risada aleatória, em um de quatro estilos:

| Estilo | Exemplo |
|---|---|
| subscrito | `AHHAhaₕₐₐₕahAHHAhaₕₐₐₕahAHHAhaₕₐₐₕah…` |
| arco-íris | `❤️HA🧡HA💛HA💚HA💙HA💜HA…` |
| kkkk | `kKkkKKkKkkkKKkkKkK…` |
| fontes | `𝐇𝐀ＨＡ𝙃𝘼ʜᴀ𝓗𝓐ᴴᴬ…` |

O tamanho também é sorteado. Respondendo (reply) uma mensagem, a risada vai em cima dela; sem reply, em cima do próprio `/haha`.
